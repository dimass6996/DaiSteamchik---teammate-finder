# DaiSteamchik: Teammate Finder

## О проекте

**DaiSteamchik** — это платформа в формате чат-бота (мини-соцсеть для геймеров), предназначенная для быстрого и точного поиска тиммейтов для совместных игр в Steam.

Бот устраняет проблему ручного поиска на форумах и в открытых чатах, сопоставляя игроков по игровым дисциплинам, текущему рангу, прайм-тайму, стилю игры и уровню социальной надежности (Trust Factor). Основу системы составляют: профиль игрока, алгоритмический мэтчинг, оперативные LFG-лобби и система взаимной репутации.

## Профиль и характеристики игрока

Каждый профиль содержит связку аккаунта с игровыми дисциплинами и игровыми метаданными.

**Ключевые параметры анкеты:**
* **Games & Roles** — список дисциплин (Dota 2, CS2, Rust, Apex) и позиций (Carry, Support, IGL, Awper).
* **Skill / Rank** — текущий ранг / MMR в выбранной игре.
* **Prime-Time** — диапазон часов по часовому поясу игрока (например, 19:00–23:00 МСК).
* **Playstyle** — стиль игры: Casual (для фана и отдыха) или Tryhard/Competitive (нацеленность на победу и рейтинг).

### Шкала рангов репутации (Trust Factor)

Вместо сортировки только по внутриигровым рангам ключевым модификатором совместимости и выдачи анкет выступает уровень социальной надежности игрока:

```text
Toxic / Изгой    ██                  ×0.25 (Теневой бан, поиск только в пуле нарушителей)
Newbie / Новичок ██████              ×1.00 (Новый аккаунт, нейтральный статус)
Friendly / Бро   ██████████          ×1.25 (Положительная динамика, первые одобрения)
Reliable / Про   ████████████████    ×1.75 (Надежный тиммейт, отсутствие жалоб на ливы)
Mentor / Ветеран █████████████████████ ×2.25 (Высокий траст, помощь начинающим)
Legend / Легенда ████████████████████████████ ×3.00 (Максимальный приоритет в выдаче и LFG)
```

**Механика обновления репутации:**

После завершения совместного матча пользователям предлагается оставить отзыв:
* **Endorsement (Похвала):** начисление кармы (коммуникабельность, командная игра, координация).
* **Report (Жалоба):** списание кармы (токсичность, намеренный выход из игры до финала, помеха матчу).
* **Skip (Пропуск):** нейтральный исход (без изменения счета кармы).

## Режимы поиска

### 1. Мэтчинг анкет (Swipe Mode)
Игрок просматривает персональные карточки других пользователей с фильтрацией по интересующей дисциплине.
* **Доступные действия:** Лайк / Пропуск.
* При взаимном подтверждении бот отправляет обоим пользователям уведомление со ссылками на Telegram-аккаунт и профиль Steam.

### 2. Экспресс-LFG («Ищу пати сейчас»)
Функционал для оперативного добора игроков в лобби:
* Заявка имеет ограниченное время жизни: $T_{life} = 15..60$ минут (задается при публикации).
* По истечении времени статус заявки автоматически переводится в архивный.
* Пользователи, отметившие статус «Готов играть сейчас», получают прямое системное уведомление.

### 3. Модерация через репутацию
Профили с высоким рейтингом Trust Factor получают приоритетное ранжирование в поиске и доступ к верифицированным LFG-лобби. Профили с критическим числом жалоб временно лишаются возможности создавать публичные LFG-заявки.
