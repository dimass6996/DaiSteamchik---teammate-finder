# Задачи DaiSteamchik

### Задача 1. Основные команды
- Подключить Telegram-бота.
- Реализовать команды `/start`, `/help`, `/about`, `/author`.

### Задача 2. Анкета пользователя
- Реализовать регистрацию: имя, Steam, время игры, роль и игры.
- Добавить проверку данных, команды `/back` и `/cancel`.
- Сохранять анкеты в базе данных.
- Реализовать просмотр анкеты.

### Задача 3. Управление анкетой и поиск тиммейтов
- Добавить inline-кнопки для просмотра, изменения и удаления анкеты.
- Реализовать команду `/search` — список доступных пользователей с их ID.
- Добавить выбор пользователя по ID для отправки сообщения.
- Реализовать ввод текста сообщения и Telegram-контакта отправителя.
- Отправлять выбранному пользователю сообщение с текстом и контактом отправителя.
