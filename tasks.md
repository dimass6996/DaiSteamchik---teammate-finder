# План разработки DaiSteamchik

---

### Задача 1. Базовый каркас проекта и первые команды
Цель: поднять каркас приложения и реализовать разогревочное задание преподавателя.

* **Разработчик 1:**
  * Настроить Maven (`pom.xml`) и файл `.gitignore`.
  * Создать интерфейс `Command` и реестр `CommandRegistry`.
  * Написать команду `/help` (динамический вывод команд без дублирования) и юнит-тесты к ней.
* **Разработчик 2:**
  * Подключить Telegram Bot SDK, реализовать запуск бота и безопасное чтение токена.
  * Реализовать класс команды `/about` (описание концепции проекта).
  * Реализовать класс команды `/author` (информация об авторах) и юнит-тесты к командам.

---

### Задача 2. Доменная модель и профиль игрока
Цель: спроектировать структуру пользователя, хранение данных и просмотр анкеты.

* **Разработчик 1:**
  * Создать модель данных `User` и `GameProfile` (ник, ссылка на Steam, список игр, роли).
  * Написать команду `/profile` (отображение карточки игрока в чате).
  * Написать тесты на создание профиля и корректное форматирование карточки.
* **Разработчик 2:**
  * Создать интерфейс репозитория `UserRepository` и его потокобезопасную реализацию в памяти (`InMemoryUserRepository`).
  * Написать логику проверки наличия профиля: если анкеты нет, бот предупреждает и предлагает регистрацию.
  * Написать тесты на сохранение, обновление и поиск пользователей по ID.

---

### Задача 3. Пошаговая регистрация анкеты (Диалоги)
Цель: реализовать пошаговое заполнение данных игрока через диалог и кнопки.

* **Разработчик 1:**
  * Спроектировать состояния диалога (ввод ссылки на Steam, ввод прайм-тайма).
  * Написать обработку шагов ввода текста и валидацию (формат Steam-ссылки, формат времени `19:00-23:00`).
  * Написать юнит-тесты на валидаторы ввода.
* **Разработчик 2:**
  * Спроектировать шаг выбора игр и ролей (Dota 2, CS2 и т.д.).
  * Реализовать Inline-кнопки для выбора дисциплин и обработку нажатий (Callback Query).
  * Написать сохранение собранных с кнопок данных в профиль пользователя.

---

### Задача 4. Система рангов репутации (Trust Factor)
Цель: внедрить социальную шкалу надежности игроков и систему оценок после игр.

* **Разработчик 1:**
  * Создать перечисление рангов `ReputationRank` (от «Изгой» до «Легенда») с весовыми коэффициентами.
  * Реализовать логику начисления/списания кармы за похвалу (`Endorsement`) и жалобу (`Report`).
  * Написать тесты на автоматическую смену ранга при достижении пороговых значений очков.
* **Разработчик 2:**
  * Реализовать сценарий оценки тиммейта после игры (кнопки «Похвалить», «Пожаловаться», «Пропустить»).
  * Добавить отображение текущего ранга репутации в команду `/profile`.
  * Реализовать ограничение доступа: блокировка определенных действий для игроков с рангом «Изгой».

---

### Задача 5. Поиск и мэтчинг тиммейтов (Свайпы)
Цель: сделать рекомендательную ленту игроков с возможностью взаимного лайка.

* **Разработчик 1:**
  * Реализовать алгоритм совместимости двух игроков по формуле (игры + время + множитель репутации).
  * Написать логику фильтрации: исключать токсичный пул и уже просмотренные анкеты.
  * Покрыть алгоритм скоринга юнит-тестами.
* **Разработчик 2:**
  * Реализовать команду `/search` и выдачу карточки подходящего игрока с кнопками «👍 Лайк» и «👎 Пропуск».
  * Реализовать логику взаимного мэтча: уведомление обоим игрокам с передачей контактов (`@username` и Steam).
  * Написать тесты на фиксацию взаимных лайков.

---

### Задача 6. Экспресс-заявки LFG («Ищу пати прямо сейчас»)
Цель: добавить доску срочных объявлений с автоматическим удалением по таймеру.

* **Разработчик 1:**
  * Создать модель заявки `LfgRequest` и репозиторий для активных заявок.
  * Настроить фоновый таймер (`ScheduledExecutorService`), который автоматически удаляет заявки старше 15–30 минут.
  * Написать тесты на создание и автоматическое устаревание заявки.
* **Разработчик 2:**
  * Реализовать команду `/lfg` для публикации быстрой заявки (выбор игры и нужного числа тиммейтов).
  * Реализовать механизм рассылки уведомлений игрокам, находящимся в режиме «Готов играть сейчас».
  * Добавить проверку: запрет публикации заявок пользователям с низким рейтингом доверия.

---

### Задача 7. Сохранение данных и финализация проекта
Цель: обеспечить сохранность базы при перезапусках, отполировать код и подготовить защиту.

* **Разработчик 1:**
  * Реализовать сохранение и загрузку профилей пользователей в файл (JSON или простая файловая БД SQLite/H2).
  * Написать интеграционные тесты для проверки сквозного цикла (регистрация -> мэтч -> отзыв).
* **Разработчик 2:**
  * Реализовать глобальный перехватчик ошибок бота (защита от падений при некорректном вводе).
  * Проверить актуальность команды `/help` и обновить документацию в `README.md`.
